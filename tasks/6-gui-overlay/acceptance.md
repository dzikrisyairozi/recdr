# Acceptance: 6-gui-overlay

One line per success criterion in `spec/6-gui-overlay/spec.md`. Criteria 1 to 10 are tests and run in CI on three systems. Criteria 11 to 23 were run on Windows 11 Home 10.0.26200 (three 1920 by 1080 monitors at scale 1) on 2026-11-19 by the agent, with the release build. The agent may not move the pointer or press keys on the owner's desktop: it pressed the app's buttons through UI Automation (egui's AccessKit tree, no input sent), filled the save dialog with window messages, read window rectangles and the window under a point with Win32 queries, and compared screenshots. What needs a real drag or click is marked "owner". Recordings of the desktop stayed in the scratchpad. macOS (Task 14): run on 2026-11-20 on macOS 26.6.2, Apple M5, one display at scale 2, release build. The agent pressed the app's buttons through the Accessibility API (AXPress and AXValue on recdr's own elements; no mouse or keyboard events), read window places and levels from the CoreGraphics window list, and sampled pixels from screenshots of the frame's edges only.
